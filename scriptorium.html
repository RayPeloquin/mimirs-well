The Scriptorium

Research cycle map: start here or find the next stage.

The Scriptorium is the private drafting stage of the Well. See How to misread the Well. Capture an unfinished thought, its question, uncertainties and possible related records before deciding whether it deserves review.

Download the blank offline notebook. Save it outside the public Git repository and open the downloaded file directly. The editor refuses to run on the hosted website.

Working method

  1. Capture a thought without having to justify a finished design.
  2. Mark it draft, parked or ready for private review.
  3. Export a private archive and verify it was saved. Reopen that JSON file in the offline notebook next time.
  4. When appropriate, write a separate bounded review packet. Do not copy private material into the packet automatically.
  5. Send the packet for human source, safety and release review before any catalog entry is considered.

Privacy boundaries

The notebook uses session memory, not website storage, accounts or a remote database. It contains no automatic saving, synchronization, analytics, network submission or publication action. Files are not encrypted; device access and backup security remain your responsibility. Closing the notebook without exporting can lose work. The browser cannot verify whether an export was saved successfully.

Do not place private archives in the public repository. The public Well contains only the empty tool and these instructions, not notebook contents. Existing sticky notes are not automatically read or imported.

The Orrery provides reviewed research links; possible related IDs in a private note remain unverified. Publication safeguards still apply to all proposed releases.
