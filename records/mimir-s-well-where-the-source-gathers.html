Summary

The public gathering place for Mr. Peloquin and the Court of the Synthetic: a browsable research/design catalog connecting project purposes to public sources, evidence, limitations, attribution and next checks. Asteris’ Workbench provides a dated handoff snapshot.

Evidence and limits

The implementation consists of a static page, generated catalog and read-only project registry. Recent maintenance included JavaScript syntax checks, selected behavior checks and exact readback of committed files. Search checks cover punctuation, word order, archived names, category labels and cache reuse/refresh. Public editing, save, import and persistence controls were removed. Registry content comes from published source, with no visitor write API. The visitor log is a separate GitHub issue whose comments do not modify project records. This maintenance pass has not completed a full browser/device audit or independently rerun every project's research. Catalog inclusion and expanded documentation are not experimental validation. A committed change must still propagate through GitHub Pages before the live page serves it.
