CONSCIENCE-01 — Bounded machine advisory layer

Evidence type describes the public artifact, not a validation or safety certificate.

Summary

An offline bounded advisory layer that flags concerns or suggests preferences among options the host controller already permits. Shadow mode is the default; the adviser has no protocol authority to issue actuator commands, stop, veto or override.

Evidence and limits

The brief reports 35 checks and 10,000 synthetic cases, with no shadow-choice changes, influence-bound breaches or faulty-advice influences in that suite. These are saved software results, not rerun here. A constructed toy loss measure improved in 91 cases and worsened in 9; remaining cases tied. This does not establish moral judgment or better robot autonomy. Timing, physical noninterference, process/resource isolation and operator usefulness remain unvalidated.

Contributors

The brief describes assembly from LANTERN-1, Edge Reflex Mesh, advisory/provenance work, U.I. Worlds familiars and CRUCIBLE testing patterns. Grok, Claude and Gemini challenged the design; reviews were not independent code execution or certification. Individual assembly authorship remains to be consolidated.
