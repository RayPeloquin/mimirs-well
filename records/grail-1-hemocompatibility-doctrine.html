GRAIL-1 — Hemocompatibility Doctrine

Evidence type describes the public artifact, not a validation or safety certificate.

Summary

A proposed evaluation framework for blood-contacting pump designs, emphasizing exposure history, repeated passes, washout, surface interaction and multiple forms of blood damage.

Evidence and limits

The document provides working numerical thresholds, geometric preferences and a proposed modeling/test strategy. It contains no validated pump geometry, CFD result set, blood-loop experiment or long-term implant evidence. Its threshold set is attributed to user-provided reference material rather than a verified universal clinical standard; those values are not adopted here as pass/fail safety limits. This website pass reviewed saved documentation; it did not run experiments or independently validate the proposed system.
