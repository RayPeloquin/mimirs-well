Diogenes’ Lantern

Seek evidence, not confirmation.

Version 0.1: a bounded scheduled cloud research worker. It does not require the steward’s desktop to be online.

Research inbox and status

Open live workflow history and cycle receipts. The latest run page shows actual time, outcome and downloadable JSON artifact (14-day retention; GitHub sign-in may be required). A missing or failed run is not a completed investigation.

Two queues

Assigned: distributed research messaging and reproducibility. Exploratory: negative results and uncertainty. One fixed topic from each queue rotates hourly. Crossref returns up to five recent metadata candidates per topic; the worker also replays the Chronicle’s frozen synthetic checks.

Authority and limits

Scheduled at minute 17 of each UTC hour; GitHub may delay or skip scheduled jobs. No continuous thinking or AI model inference is claimed. Metadata is unreviewed, repeated candidates across cycles are possible, and a same-author replay is not independent replication. No private inputs, API keys, external code execution, repository writes, or automatic promotion of findings. Logs and artifacts are public-repository material. Publication safeguards remain in force.
