How to read evidence and record labels

Expanded record: source reviewed and summarized; not a validation claim. Awaiting source review: catalog placeholder.

Illustrated concept: visual or descriptive proposal. Model proposed: a candidate model, not necessarily executed. Calculation-only design: numerical reasoning without physical validation. Materials comparison proposed: candidate comparison awaiting testing. These describe evidence types, not a universal maturity ranking.

The full catalog groups evidence under calculation, prediction or simulation, software tests, and concept or design review. “Evidence type uncategorized” means a source summary is available and the catalog has yet to assign a type.

01 /Mechanical measurement

SKEPTIC-1

Evidence type: Numerical model

Reversible mechanical probing: the ideal-model study shows an asymmetric brace separates mirrored faults while a center brace preserves ambiguity. Numerical evidence only; no built instrument.

Not demonstrated
No built instrument or measured fault discrimination.
Next falsifiable test (proposed)
Blind numerical rerun with mirrored cases; reject if asymmetry does not separate them. Test planning guide

02 /AI & safety

CRUCIBLE

Evidence type: Vehicle simulation + software tests

In 40 simulated rover scenarios, the baseline controller broke its rules eight times. The guarded controller broke them zero times. The quadrotor results were mixed, and neither vehicle was tested in the field.

Not demonstrated
No field validation; mixed quadrotor outcomes.
Next falsifiable test (proposed)
Repeat held-out synthetic fault cases against the same baseline; count violations and refused actions. Test planning guide

Ghostglass

Evidence type: Statistical simulation + software tests

CHRONOVISOR–N/S: a synthetic on/off statistical reference with published experiment code, saved baseline results, and a documented 15-test protocol suite. These software checks do not demonstrate a working neutrino detector; hardware remains unvalidated.

Not demonstrated

Next falsifiable test (proposed)
Freeze independent synthetic null/injected data and compare false alerts at matched sensitivity. Test planning guide

06 /Engineering

BRIDLE-3

Evidence type: Thermal simulation

In a simulated cooling fault in one engine module, a local cooling reserve lowered the peak temperature rise. The model uses scaled temperatures and still needs calibration against engine measurements.

Not demonstrated
No calibrated engine or physical cooling performance.
Next falsifiable test (proposed)
Check sensitivity to uncertain model inputs and compare against a fixed no-reserve baseline. Test planning guide

07 /Biology

ECHO-Rx

Evidence type: Mathematical model

A model asks what happens after a proposed cell therapy stops producing protein. In one example, protein already released makes the target level keep rising after shutdown. Biological and clinical testing remain open.

Not demonstrated
No biological or clinical validation.
Next falsifiable test (proposed)
Reproduce the model against a no-residual baseline; test whether the predicted post-shutdown rise persists. Test planning guide

08 /Physics

Temporal Reflection Chamber

Evidence type: Timing model

The timing model predicts that two pulse features should return in reverse order under a specified switch condition. The chamber still needs a measurement that distinguishes that signature from ordinary echoes.

Not demonstrated
No measured temporal-reversal signature.
Next falsifiable test (proposed)
Compare synthetic predicted return ordering against ordinary echo controls using a frozen classifier. Test planning guide
