# Echo Bowl

A passive radio receiver would listen for existing transmissions scattered by celestial objects. A reference antenna would help distinguish candidate echoes from interference.

## Evidence

The diagram supplies no observed echo, calibrated sensitivity measurement or demonstrated range.

## Proposed next check

Use blinded synthetic recordings with and without echoes. Measure detection and false alarms as interference changes.
