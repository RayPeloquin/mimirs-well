01 / The three questions

Keep intent, evidence and hypothesis apart.

01 / INTENDED

What we intended

Study a toy registry that authorizes local state changes using update witnesses rather than reconstructing the entire registry each time.

A goal is not an experimental result.

02 / DOCUMENTED

What actually happened

The reviewed archive retains a failed submitted v0.1 run and a corrected local v0.2 pilot. The report lists 456 scenario rows, 18 commit controls and 640 agreeing benchmark pairs. Shared validation/controller logic limits independence; local witnesses do not immediately detect arbitrary backing-store corruption.

This describes the available source record; no new tests are implied.

03 / POSSIBLE CROSSOVER

What else might this be useful for?

A bounded, provenance-preserving update check could inform transparent changes to a research registry, if recovery, independent code and corruption tests are added. It cannot be inherited as proof of the larger GO-CUBE designs.

New hypothesis only; independent validation needed.

Evidence boundary: Not a Liberty Field Governor, formal verification, deployment safety result or independent external replication.
