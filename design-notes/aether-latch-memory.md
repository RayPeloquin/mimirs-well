# Aether-Latch Memory

**Status:** Archived concept image only; no demonstrated prototype.

## Public concept

A proposed AI-device memory hierarchy placing a ferroelectric persistent cache between volatile main memory and flash storage.

An AI SoC and LPDDR memory feed an imagined HZO-based FeFET persistent cache ahead of NAND flash. The intended use is to preserve selected application state through power interruptions and potentially reduce storage traffic.
