# AC² Cognition Engine

**Status:** Archived research concept; not independently validated or certified.

## Purpose and proposed mechanism
Structured opposition between opportunity and integrity reviewers before a separate governance gate. Proposed outputs include ACT, ASK, DELAY, REFUSE, ESCALATE and SHRINK SCOPE.


This concept concerns competing internal assessments before the governance gate; Conduct Architecture concerns permission at the execution boundary. See also [related archive note](conduct-architecture.md).

Example to test: an opportunity reviewer recommends an action based on stale memory while the integrity reviewer sees contradictory evidence. This is a proposed failure case, not an observed result.
